# Soirée — 婚活・合コン用プロフィール＆スケジュールアプリ

Next.js 15（App Router）／TypeScript。データベース不要で、そのまま Vercel にデプロイできます。

## 機能
- **ホーム**：イベント概要と、当日は「進行中／次」のプログラムを表示
- **スケジュール**：タイムテーブル（当日は現在時刻に合わせてハイライト）と会場案内
- **自己紹介カード**：入力内容は端末に自動保存。QRコード／リンク／共有シートで他の参加者へ送れます
- **名刺帳**：受け取ったカードを保存し、「気になる」印とメモ（自分だけに表示）を付けられます
- **連絡先**：運営への電話・メール・LINE・Instagram、当日スタッフ、注意事項

カードの内容は共有リンク（URL）にエンコードされるため、サーバー側にはデータを保存しません。

## 開催ごとの編集
`src/data/event.ts` を書き換えるだけで、イベント名・日付・スケジュール・連絡先が更新されます。
`date`（`YYYY-MM-DD`）が当日と一致したときに進行状況が表示されます。
※ 現在の電話番号・メール・LINE などは**ダミー**です。公開前に差し替えてください。

## ローカル起動
```bash
npm install
npm run dev
```

## Vercel へのデプロイ
1. このフォルダ（`konkatsu-app`）を GitHub にプッシュ
2. Vercel で「Add New → Project」からリポジトリを選択
3. リポジトリのルートにアプリがない場合は **Root Directory** に `konkatsu-app` を指定
4. Framework Preset は Next.js が自動検出されます。そのまま Deploy
